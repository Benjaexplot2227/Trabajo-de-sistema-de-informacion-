## TecnoStock

Aplicación web académica para administrar productos y registrar movimientos de inventario. Usa PHP 8, PDO, MySQL/MariaDB, HTML, Bootstrap y JavaScript.

### Requisitos del sistema

- XAMPP con Apache, PHP 8 y MariaDB/MySQL.
- Un navegador web.
- Git para trabajar con el historial.
