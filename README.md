Caso 1 Sistema de Inventario TecnoStock

## TecnoStock

Aplicación web académica para administrar productos y registrar movimientos de inventario. Usa PHP 8, PDO, MySQL/MariaDB, HTML, Bootstrap y JavaScript.

### Descripcion del caso:

El caso de TecnoStock trata de una tienda de accesorios tecnológicos que controla su inventario en una planilla, lo que provoca errores en los códigos y las cantidades, y dificulta conocer el stock real. El proyecto propone una aplicación web local para administrar productos, registrar entradas, salidas y ajustes, conservar quién hizo cada movimiento y avisar cuando un producto queda bajo su stock mínimo.

### Explicacion de solucion:

Para resolver estos problemas, se creó un sitio web local cuyo objetivo principal es la integración del registro, la consulta y la gestión de productos. Te brinda la posibilidad de buscar y administrar el catálogo, registrar transacciones de entradas, salidas y ajustes de inventario asociadas con el usuario responsable de cada movimiento, además de actualizar los niveles de stock relacionados. la intención es minimizar los errores al escribir o ingresar cantidades y facilitar el control y el seguimiento del inventario.


## Funcionalidades:

- Inicio y cierre de sesión.
- Registro, búsqueda, edición y desactivación de productos.
- Registro de entradas, salidas y ajustes de stock.
- Historial de movimientos con fecha y usuario responsable.
- Aviso de productos cuyo stock está bajo el mínimo definido.

### Requisitos del sistema:

- XAMPP con Apache, PHP 8 y MariaDB/MySQL.
- Un navegador web.
- Git para trabajar con el historial.
