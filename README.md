# Trabajo-de-sistema-de-informacion-
Caso_1_Sistema_de_Inventario_TecnoStock

## Descripcion del trabajo

TecnoStock es un sistema web académico para apoyar el control de inventario de una tienda de accesorios tecnológicos. Su objetivo es reunir la información de los productos y conservar un historial de los cambios de existencias.

El proyecto se desarrolla siguiendo el modelo en cascada. Su alcance contempla el registro y consulta de productos, el control de entradas y salidas, los ajustes de stock mediante movimientos y la identificación de productos bajo el nivel mínimo definido.

### Funciones contempladas del proyecto

.Inicio y cierre de sesión.
.Registro, consulta, búsqueda, edición y desactivación de productos.
.Registro de entradas, salidas y ajustes de inventario.
.Actualización de existencias junto con el registro del movimiento.
.Consulta del historial de movimientos.
.Aviso de productos cuyo stock está bajo el mínimo definido.
